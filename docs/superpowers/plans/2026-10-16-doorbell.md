# Doorbell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code mod that shows GitHub PR events (review requests, new comments, approvals, releases containing your merges) on a band above the prompt and as macOS notifications.

**Architecture:** One interactive session per machine holds a lease and polls GitHub with a single `gh api graphql` request. Pure trigger functions turn the response into band items and notification events, `reduce` folds them into a `State` saved atomically to `~/.cache/doorbell/state.json`, and every session draws its band from that file.

**Tech Stack:** Claude Code mod SDK (`claude-code`, `claude-code/testing`), TypeScript + JSX (`h` factory), `gh` CLI, GitHub GraphQL API.

**Spec:** `docs/superpowers/specs/2026-10-16-doorbell-design.md`

## Global Constraints

- No Node APIs. Everything outside the module goes through `$`. Helpers that do I/O take a narrow `io: Io` (Task 1) instead of the whole `$`, so unit tests can pass an in-memory fake. The real `$` is passed where an `Io` is expected.
- Time comes from `$.clock.now()` (epoch ms) and is passed into pure functions as `now`. Pure modules never read the clock.
- The session id is `await $.session.id()`, read once in `session.start` and kept for the module's life as the lease token.
- The state atom is `atom({ plugin: 'doorbell', key: 'state' } as const, EMPTY, { shape: 'v1' })`. Bump the shape tag whenever `State` changes. Session-local flags (in flight, gh missing, last heartbeat) are module variables, never in `State`, because `State` is shared through the file.
- Shared directory `~/.cache/doorbell/`, mode 0700. Files: `lease.json`, `lease.lock/`, `state.json`.
- Timings: heartbeat 20 000 ms, lease TTL 90 000 ms, follower re-read check 10 000 ms, stale lock 5 000 ms, sleep gap 40 000 ms, stale band 180 000 ms, `gh` timeout 30 000 ms, `gh --version` timeout 5 000 ms.
- Search sizes: `mine` first 30, `rr` first 30, `merged` first 50. Merged lookback 14 days. `seen` keys pruned when unobserved for 30 days.
- Notification copy and band copy are fixed by the spec's tables, verbatim. `$.ui.notify` is called as `$.ui.notify(\`${title}: ${body}\`, { title: 'Doorbell' })`.
- `userConfig`: `pollSeconds` (60, floor 30), `fadeMinutes` (5), `includeBots` (false), `notify` (true).
- Timer callbacks are wrapped as Pilot Light does: `$.clock.every(ms, () => void fn().catch(err => $.ui.log(\`doorbell: ${String(err)}\`)))`.
- Before each commit, run `claude plugin validate .`, `claude plugin test .` and `tsc -p .` from the mod folder; all three must pass. Never commit `.remember/`.

## Review Focus

1. **A comment posted between your push and the next poll** (the laptop was asleep for an hour). The comment is newer than your push commit, so it shows. Pinned in Task 4.
2. **Two sessions start at the same moment.** Exactly one wins the lease, and the loser leaves the winner's lock intact. Pinned in Task 7.
3. **Waking after an hour with many events.** At most one notification per PR (kinds collapse by priority), a single summary above 3 PRs, and approvals shown for `fadeMinutes` from first sight. Pinned in Task 6.
4. **A release compare that keeps failing** (tag deleted, unknown commit, repo renamed). Only that repo's PRs stay waiting, and no failure repeats every poll. Pinned in Tasks 2 and 5.
5. **`gh` missing from one session's PATH** (launched from an IDE). `/opt/homebrew/bin/gh` is found. A session that still cannot find it does not take the lease from sessions that can. Pinned in Tasks 2 and 9.

- Produces:

```ts
export type GhOutcome =
  | { kind: 'ok'; data: Data; failedPaths: string[] }   // distinct errors[].path[0]
  | { kind: 'rate'; retryAfterMs: number | null; resetAt: number | null }
  | { kind: 'auth' } | { kind: 'offline' } | { kind: 'query'; message: string }
export function parseGh(r: { exitCode: number; stdout: string; stderr: string }): GhOutcome
export function findGh(io: Io): Promise<string | null>
export function runGh(io: Io, gh: string, built: Built): Promise<GhOutcome>
// backoff.ts
export function afterFailure(prev: State, o: Exclude<GhOutcome, { kind: 'ok' }>, now: number): Pick<State, 'backoffUntil' | 'failures' | 'error'>
export function afterSuccess(partial: boolean): Pick<State, 'backoffUntil' | 'failures' | 'error'>
// schedule.ts
export function shouldPoll(s: State, lastBeatAt: number, now: number, cfg: Config): boolean
```

- **Classification order in `parseGh`** (never from the exit code alone, because exit 1 is normal when the response is partial):
  1. Empty stdout: exit 4 or stderr matching `/gh auth login/` means `auth`; anything else means `offline`.
  2. Split headers from the body at the first `/\r?\n\r?\n/`. The status comes from `/^HTTP\/\S+ (\d{3})/`, and headers are matched case-insensitively.
  3. 401 means `auth`.
  4. It is `rate` when any of these hold: the status is 403 or 429; `x-ratelimit-remaining` is `0` and there is no `data`; the body matches `/rate limit/i`; or an error has `type: 'RATE_LIMITED'`. `retryAfterMs` comes from `retry-after`, and `resetAt` is `x-ratelimit-reset` × 1000.
  5. A status of 500 or above means `offline`.
  6. A body with `data` means `ok`.
  7. A body with `errors` and no `data` means `query`, with the first error's message.
- `runGh` maps a rejected `io.process.run` (a timeout, since `findGh` already proved the binary starts) to `offline`.
- **`afterFailure` waits:**

| Outcome | Wait | `error` |
|---|---|---|
| `rate` | `retryAfterMs` if present, else until `resetAt`, else 60 s doubling per prior failure, capped at 15 min | `'rate'` |
| `offline` | 15 s, 30 s, 60 s, then 5 min | `'offline'` only once `failures` reaches 3, else unchanged |
| `auth` | 5 min | `'auth'` |
| `query` | 60 s doubling, capped at 15 min | `'query'` |

- **`shouldPoll`** returns true when `now ≥ s.backoffUntil` and either `now − s.lastAttemptAt ≥ max(cfg.pollSeconds, 30)·1000`, or `lastBeatAt > 0 && now − lastBeatAt > 40_000` (the machine slept).

### Task 9: Wire the mod

**Files:** Replace `hooks/register.tsx`; create `tests/doorbell.test.tsx`

**Interfaces:**
- Consumes: everything above.
- **Module variables:** `sessionId`, `dir`, `gh: string | null`, `ghMissing`, `inFlight`, `lastBeatAt`, `lastMtime`, `cfg`.
- **Behaviour, in `register(on, options)`:**
  - **`session.start`** (only when `e.isInteractive`):
    - Reset `inFlight = false`.
    - Read `sessionId = await $.session.id()`, and set `dir = cacheDir(await $.env.get('HOME'))`.
    - Call `ensureDir`, then load `readState` into the atom when it is non-null.
    - Set `gh = await findGh($)` and `ghMissing = gh === null`.
    - Start `heartbeat` every 20 000 ms and `followerRefresh` every 10 000 ms, both wrapped as in the Global Constraints.
  - **`heartbeat`:**
    - Return at once when `ghMissing`, so a session without gh never takes the lease (Review Focus 5).
    - Otherwise call `tryLead`. As leader, poll when `!inFlight && shouldPoll(state, lastBeatAt, now, cfg)`. Set `lastBeatAt = now` either way.
  - **`poll`:**
    1. Set `inFlight = true`.
    2. `built = buildQuery(s, now)`, then `o = await runGh($, gh, built)`.
    3. On `ok`: `{state, notes} = reduce(s, o.data, o.failedPaths, built.aliases, now, cfg)`.
    4. Otherwise: `state = { ...s, lastAttemptAt: now, ...afterFailure(s, o, now) }`. When `o.kind === 'query'`, also spread in `giveUpCompares(s, built.aliases)`.
    5. `writeState`, set the atom, and `send($, notes)` when `cfg.notify`.
    6. Set `inFlight = false` in a `finally`.
  - **`followerRefresh`:** when `stateMtime` differs from `lastMtime`, `readState`, and set the atom only if the result is non-null. Always call `$.ui.invalidate('ui.render')`, so `stale Nm` keeps counting.
  - **`session.end`:** `release` unless `e.reason === 'clear'`.
  - **`ui.render` for `AbovePrompt`:** return `next(e)` on `hasSurvey` or when there are no segments. Otherwise draw `segments(read($, atom), await $.clock.now(), ghMissing)` as `Box flexWrap="wrap" gap={2}` of `Text`, `dimColor` for dim and a warning colour for warn, as in Pilot Light.
- **Test world:** stubs for every `$` call the mod makes, because an unstubbed call throws in the kit.
  - `session.id` (`() => ({ value: 'S1' })`) and `env.get` (`'/home/t'`).
  - `fs.read`, `fs.write`, `fs.exists` and `fs.stat`, all backed by one Map. `read` and `stat` reject for missing paths.
  - `process.run`, which routes `mkdir`/`rmdir`/`mv` to the Map, `gh --version` to exit 0, `gh api graphql` to a queue of `ghOut(...)` strings, and `osascript` to a recorder.
  - `ui.notify` (with `as const` on `isSent`/`channel`), `ui.log`, `ui.invalidate`, `session.start` and `session.end`.
